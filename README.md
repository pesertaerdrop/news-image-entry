**Wednesday 18 November 2026: the day's world news on one front page** — 40 stories, 7 regions, one page. Eleven illustrated lead stories (APEC in Shenzhen, the Iran–Gulf drone war, Voyager 1's one-light-day milestone, 141 drones over Ukraine, the Fed minutes, Cyclone Akvan, Amnesty's Sudan report, the EU's €45bn Ukraine loan, UK inflation at 3.6%, tanks in central Gaza, Jeffries' 251–11 Speaker nomination), a world map of where it happened, 29 more briefs, stat boxes and a date check of what was deliberately left out. Every story happened, or was first reported, on Wednesday 18 November 2026. All eleven illustrations were generated from structured prompts built with prompts.chat (`npx prompts.chat`); the page itself is HTML/CSS rendered to a 1024×1024 PNG, and the program simply copies that image to the output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
